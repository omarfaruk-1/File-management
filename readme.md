# 📂 Node.js File System CLI

A simple command line application built with **Node.js** that allows users to manage files and folders directly from the terminal.

This project provides an interactive menu where users can perform common file system operations such as creating folders, creating files, writing content, reading files, deleting files or folders, and listing directory items.

The application uses Node.js built-in modules and a colorful CLI interface to make the terminal experience easier and more user friendly.

---

## 🚀 Features

* 📁 Create folders
* 📄 Create files with initial content
* ✏️ Add or append content to files
* 📖 Read file content
* 🗑️ Delete files
* 🗂️ Delete folders
* 📋 List all files and folders inside a directory
* 🎨 Colorful command line interface using chalk

---

## 🛠️ Technologies Used

* Node.js
* fs/promises (File System API)
* readline/promises
* chalk

---

## ▶️ How to Run

Install dependencies:

```bash
npm install
```

Run the application:

```bash
node index.js
```

---

## 📌 Purpose of the Project

This project was built for learning and practicing:

* Node.js File System operations
* Async/Await in JavaScript
* Building CLI (Command Line Interface) applications
* Writing modular and clean code structure

It is a beginner-friendly project for understanding how Node.js interacts with the system file structure.
